## VSynC Medical Monitoring Platform

**Senior Project Manager | Medical Device Technology | Hardware + Firmware + Software | QMS | Regulated Delivery**

---

## 📌 Executive Summary

The Medical Early Warning System (MEWS) is a regulated medical device platform designed for **real-time patient monitoring, physiological data collection, clinical decision support, and early detection of patient deterioration**.

The platform integrates **medical hardware, embedded firmware, cloud services, mobile applications, and backend systems** to support healthcare providers in monitoring patient conditions and facilitating timely clinical intervention.

As **Senior Project Manager**, I managed delivery across software, firmware, hardware, quality, compliance, and operations.

The project was delivered within an **ISO 13485 Quality Management System environment**, with software lifecycle practices aligned with **IEC 62304** and risk-management activities aligned with **ISO 14971**.

## 💡 Key Lessons Learned

### 1. Cross-functional dependencies must be managed as part of the project plan

Hardware, firmware, software, quality, and validation cannot be planned independently when they form one product.

### 2. Quality must be integrated into delivery

QMS activities, documentation, traceability, and risk management need to progress alongside engineering work.

### 3. Delivery methodology should reflect the product

Agile software development can coexist with structured hardware, quality, and regulated lifecycle activities.

### 4. Technical changes require lifecycle awareness

Engineering changes need to be evaluated for their impact on requirements, risk, testing, validation, and release readiness.

### 5. Production readiness is a cross-functional milestone

A product is not production-ready simply because engineering work is complete.
